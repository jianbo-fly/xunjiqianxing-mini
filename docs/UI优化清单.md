## 📋 剩余优化项

### #5 图片策略 - 视差轮播 ⭐ 高优先级

**问题**：首页轮播图当前是普通平铺滚动，缺乏层次感

**优化方案**：
- 用户滚动页面时，轮播图以 0.5-0.7 倍速缓慢移动
- 使用 `scroll-into-view` 事件触发/停止视差
- 增强页面滚动层次感，更显专业

**涉及文件**：
- `pages/index/index.wxml` — swiper 组件
- `pages/index/index.js` — 滚动事件处理
- `pages/index/index.wxss` — 视差动画样式

**预估工时**：5 分钟

---

### #1 信息密度分级 📊 中优先级

**问题**：首页信息过密，关键信息缺乏视觉锚点

**优化方向**：
- 价格数字放大：`48rpx` → `52-56rpx`，成为卡片视觉焦点
- 销量/评分等次要信息字号缩小：`20rpx` → `18rpx`
- 价格与其他内容间距拉大，强化主次关系

**涉及文件**：
- `pages/index/index.wxss` — `.route-card__price-*` 系列样式
- `pages/route/list/index.wxss` — `.list-route-card__price-*` 系列样式

**预估工时**：10 分钟（需调试视觉效果）

**依赖**：需设计稿确认具体数值

### #2 价格视觉锚点 🎯 中优先级

**问题**：价格区域缺乏视觉强化，促销感不足

**优化方案**：
1. **价格背景胶囊**：在价格区加浅红底色块，`¥符号` + `数字` 在胶囊内突出
2. **折扣标签强化**：`立减 ¥200` 改为红底白字 + 阴影
3. **限时文案**：`/人起` 旁加"限时抢购"红色角标

**涉及文件**：
- `pages/index/index.wxss`
- `pages/route/list/index.wxss`
- `components/business/route-card/index.wxss`

**预估工时**：15 分钟

**依赖**：需设计稿确认具体样式

### #8 间距一致性 📐 低优先级

**问题**：padding/margin 大量硬编码，维护困难

**优化方案**：
- `padding: var(--card-padding)` 替代散落 `24rpx/32rpx`
- `gap: var(--spacing-md)` 替代 `24rpx`
- 使用已有 token，无需新增

**涉及文件**：
- 全部 `*.wxss` 文件，预计 50+ 处修改

**预估工时**：20-30 分钟（批量替换）

---

### #9 状态色语义化 🎨 低优先级

**问题**：状态颜色使用混乱，部分硬编码 `#16A34A/#10B981`

**优化方案**：
- 全部使用 token：`var(--color-success)` / `var(--color-warning)` / `var(--color-error)`
- 对订单、促销、用户状态统一规范
- 新增状态色变量到 `styles/variables.wxss`

**涉及文件**：
- `styles/variables.wxss` — 新增状态色 token
- 各页面 WXSS — 替换硬编码颜色

**预估工时**：15 分钟

## 🎯 优化原则

1. **视觉优先**：优先完成高视觉影响项，快速提升商业转化率
2. **向下兼容**：新增样式不影响现有功能，逐步替换
3. **设计先行**：涉及视觉细节的修改，先确认设计稿
4. **批量处理**：机械性替换用 sed/perl，减少手工出错
