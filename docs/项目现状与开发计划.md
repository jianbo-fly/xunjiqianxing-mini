# 寻迹千行 - 项目现状与开发计划

**版本：V1.0 | 日期：2026年3月**

---

## 一、项目概述

**寻迹千行**是一个综合旅游服务平台，一期聚焦跟团游和定制游业务，后续扩展租车、民宿、门票、美食等模块。

| 端 | 形态 | 技术栈 |
|---|---|---|
| C端 | 微信小程序 | 原生小程序 |
| B端 | PC Web 管理后台 | Vue3 + TypeScript + Element Plus |
| 后端 | Java 单体服务 | Spring Boot 3.2.2 + MyBatis Plus + MySQL + Redis |

#### 2. 推广二维码生成与扫码绑定链路

**完整流程：**

```
推广员 → GET /api/promoter/qrcode
  ↓ 调微信 wxacode.getUnlimited(scene=promoCode, page=pages/index/index, width=280)
  ↓ 返回 PNG bytes → wx.downloadFile → 显示在海报推广码位置

用户扫码 → 小程序启动 index.js onLoad(options.scene = promoCode)
  ↓ decodeURIComponent(scene) → wx.setStorageSync('pendingPromoCode', promoCode)

index.js onShow（每次显示时检测）
  ↓ isLogin() && pendingPromoCode 存在
  ↓ POST /api/promoter/bind { promoCode }  → 写入 user.bindpromoterId（一次性）

用户下单支付成功 → PaymentEventListener（已有逻辑）
  ↓ promoterService.recordCommission(userId, orderNo, amount)
  ↓ 查 user.bindpromoterId → 计算佣金 → 写入 PromoterCommission（待结算）
  ↓ 管理员审核后 settleCommission → 推广员 availableCommission 增加
```

**涉及文件改动：**

| 文件 | 改动内容 |
|------|---------|
| `xj-app/.../PromoterController.java` | 新增 `GET /api/promoter/qrcode` 接口，注入 `WxMaService`，调 `createWxaCodeUnlimit` 返回 PNG 字节流 |
| `xj-miniprogram/config/api.js` | promoter 模块下新增 `qrcode: '/api/promoter/qrcode'` |
| `xj-miniprogram/services/promoter.js` | 新增 `downloadQrCode()` 方法，使用 `wx.downloadFile` 携带 token 下载图片，返回本地临时路径 |
| `xj-miniprogram/pages/promoter/center/index.js` | 加载推广员信息后自动调 `loadQrCode()`；字段映射修正（`promotedCount` → `scanCount`，`availableCommission` → `points`） |
| `xj-miniprogram/pages/index/index.js` | `onLoad` 处理 `options.scene` 存储 `pendingPromoCode`；`onShow` 调 `tryBindPromoter()` 自动绑定 |

**待确认事项：**
- `POST /api/promoter/bind` 后端接收方式为 `@RequestParam`，前端发送为 JSON body，需统一（改后端为 `@RequestBody` 或前端改为 query param）
